# Pipeline de arte de textura

1. Criar a textura original em ferramenta externa.
2. Reduzir dimensões e cores para o orçamento de PS2.
3. Gerar paleta quando usar INDEX8/INDEX4.
4. Exportar para um formato intermediário que o conversor do projeto aceite.
5. Converter para layout compatível com GS/GSKit.
6. Reservar VRAM e transferir pixels/CLUT.
7. Conferir UVs, repetição, transparência e filtragem em cada fase.

Não reutilizar texturas protegidas do jogo original sem autorização. Para o remake,
usar arte própria ou recursos licenciados.
